# 🍔 Food Delivery Website

A responsive **Food Delivery Website frontend** developed using HTML, CSS, Bootstrap, and JavaScript. The website provides a simple and user-friendly interface for exploring restaurants, viewing offers, and navigating through different food delivery options.

## 🚀 Features

- Responsive food delivery homepage
- Restaurant listing
- Display of 6 restaurants
- Initially displays 4 restaurants
- "View All" option to view the remaining restaurants
- Restaurant ratings
- Special offers section
- Coupon codes
- "Order Now" buttons
- Location and delivery options
- User login page
- User signup page
- Responsive navigation
- Bootstrap icons
- Responsive design for desktop, tablet, and mobile devices
- Hover effects and modern card-based UI

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Bootstrap**
- **Bootstrap Icons**
- **JavaScript**
